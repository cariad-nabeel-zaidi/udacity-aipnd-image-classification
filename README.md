# AI Programming with Python Project

Project code for Udacity's AI Programming with Python Nanodegree program. In this project, students first develop code for an image classifier built with PyTorch, then convert it into a command line application. The project uses a pretrained VGG16/VGG13 model to classify flower images from a labeled dataset. A custom classifier is trained on top of the pretrained network using transfer learning. The train.py script allows users to train the model with configurable hyperparameters such as learning rate, hidden units, number of epochs, architecture selection, and optional GPU support, while displaying training and validation metrics. The trained model is saved as a checkpoint for reuse. The predict.py script loads the saved checkpoint and performs inference on new images, returning the top-K most likely flower classes along with their probabilities. It also supports mapping class indices to real flower names using a JSON file and can optionally use GPU for faster predictions.
